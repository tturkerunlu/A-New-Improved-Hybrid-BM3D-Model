Run:
python infer_one_demo_mode.py

Default: demo_mode=True. This runs without training/checkpoint and writes BM3D output as refine.png.
Full mode requires setting demo_mode=False and providing weights/bm3d_res_unet_best.pth.

The demo version outlines the work and demonstrates BM3D and U-Net. The full version will be published on GitHub after the article is approved.
